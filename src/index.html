Rule-based mode understands a fixed set of phrases (counting, sums, variables, FizzBuzz, factorial, Fibonacci, countdowns, greetings, times tables…) in English, Spanish, French, German and Portuguese. Claude AI mode handles any sentence in any language.

Explanation

    Rule-based mode reads a simple subset of Python or JavaScript (prints, variables, for/while/if, comments) and rewrites it in any target language. Claude AI mode translates full programs between any pair of languages, preserving behavior and idiom.
